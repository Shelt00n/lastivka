# Ластівка 🐦

Мобільна веб-версія месенджера в стилі **Telegram** з новою функцією **«Тихі години»**:
якщо співрозмовник спить, ваше повідомлення не розбудить його — сервер притримає його
й доставить, щойно в людини закінчаться тихі години (за її часовим поясом).

> Застосунок доступний за посиланням https://lastivka-unxz.onrender.com

## Демо-доступ

| Логін   | Пароль          | Для чого                                                    |
|---------|-----------------|-------------------------------------------------------------|
| `demo`  | `lastivka-demo` | основний акаунт з готовими чатами, групою та ботами         |
| `demo2` | `lastivka-demo` | другий акаунт: відкрийте в іншому браузері для перевірки реального часу |

Можна також зареєструвати власний акаунт: на сторінці входу виберіть «Реєстрація». Реєстрація відкрита, тож кожен може знайти інших за @username і листуватися.

Демо-акаунти спільні, тому вони «лише для читання»: змінити профіль, завершити чужі сеанси чи видалити акаунт не можна. Тихі години вмикати можна.

## Що вміє

**Як у Telegram**
- список чатів: папки (Усі / Особисті / Групи / Боти), пошук, глобальний пошук за @username, закріплення, вимкнення звуку, лічильники непрочитаних;
- чат: бульбашки з «хвостиками», групування, роздільники днів, «Непрочитані повідомлення», відповіді, редагування, видалення для всіх, реакції (меню або подвійний клік), копіювання, великі емодзі, посилання;
- реальний час (SSE): нові повідомлення, «друкує…», ✓/✓✓ прочитання, онлайн і «був(ла) …»;
- групи, «Збережене», боти з кнопками-клавіатурою;
- профіль співрозмовника, налаштування профілю, світла й темна (Night Blue) теми, активні сеанси з можливістю завершити, видалення акаунта з підтвердженням паролем.

**Нова функція: «Тихі години» 🌙**
- кожен задає своє вікно (наприклад, 23:00–08:00) і часовий пояс;
- відправник бачить банер «Kenji відпочиває · там 00:42. Доставимо завтра о 00:30 (там 07:30)», кнопка відправки стає «місяцем»;
- повідомлення чекає на сервері (отримувач його не бачить і не отримує подій), у відправника воно фіолетове з часом доставки;
- можна «Терміново» (надіслати одразу), «Надіслати зараз», відредагувати або скасувати відкладене;
- отримувач, якщо не спить, бачить «2 повідомлення чекають до 08:00 · Отримати зараз»;
- зміна вікна або вимкнення переносить чи доставляє відкладені повідомлення; переходи на літній/зимовий час враховано.

**Боти на зовнішніх API** (запити йдуть із сервера, з тайм-аутом, кешем і zod-валідацією)
- `@pogoda_bot`: погода в будь-якому місті ([Open-Meteo](https://open-meteo.com));
- `@nbu_rates_bot`: офіційні курси й конвертація («100 USD», «1000 грн в EUR») ([НБУ](https://bank.gov.ua));
- `@wiki_bot`: коротка довідка з української [Вікіпедії](https://uk.wikipedia.org).

## Стек

React 19 · TypeScript · Vite · TanStack Query · React Router · Hono · **PostgreSQL** (`pg`) · Zod · Vitest

База даних — PostgreSQL. Локально й у тестах використовується [PGlite](https://pglite.dev): той самий PostgreSQL, зібраний у WASM, всередині процесу. Тож для запуску не потрібно нічого встановлювати, а SQL однаковий скрізь.

## Запуск локально

Потрібен **Node.js ≥ 20.18**. PostgreSQL встановлювати не треба: без `DATABASE_URL` запускається вбудований PGlite.

```bash
npm install
```

```bash
npm run dev
```

Відкрийте http://localhost:5180 (найкраще в режимі телефона в DevTools). Локальна база (`data/pglite`)
створиться та заповниться демо-даними автоматично. Щоб працювати зі справжнім сервером PostgreSQL, задайте `DATABASE_URL`.

Продакшен-режим (один процес віддає API, SSE і зібраний фронтенд):

```bash
npm run build && NODE_ENV=production COOKIE_SECURE=false PORT=8080 DATABASE_URL=postgres://… npm start
```

## Тести та перевірки

```bash
npm test
```

```bash
npm run check
```

`npm run check` = typecheck (сервер + клієнт) → 112 тестів (сервер ганяється на справжньому PostgreSQL через PGlite) → збірка. Те саме запускає GitHub Actions ([.github/workflows/ci.yml](.github/workflows/ci.yml)).

## Деплой

- **Render (рекомендовано):** New → Blueprint → цей репозиторій ([render.yaml](render.yaml)). Blueprint створює базу PostgreSQL і веб-сервіс. `DATABASE_URL` підставляється автоматично, база закрита для зовнішніх підключень (`ipAllowList: []`).
- **Docker:** `docker build -t lastivka . && docker run -p 8080:8080 -e DATABASE_URL=postgres://… lastivka`
- **Інша база:** будь-який PostgreSQL (Neon, Supabase тощо). Досить замінити `DATABASE_URL`, схема створюється при старті.

Змінні середовища описані в [.env.example](.env.example).
