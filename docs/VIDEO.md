# Сценарій відео (≈ 4–5 хв)

Запис з телефона або DevTools у режимі iPhone. Поруч друге вікно (інкогніто) під `demo2`.

## 1. Інтро по оригіналу (30 с)
Відкрити справжній Telegram на телефоні: список чатів → чат → профіль → налаштування.
«Ось що я відтворюю: список, чат з реакціями й відповідями, профіль і налаштування».

## 2. Копія: Ластівка (2 хв)
1. Сторінка входу → «Увійти як демо».
2. Список чатів: папки, пошук (`@ken`), long-press або правий клік → закріпити / без звуку.
3. Чат з Оленою: роздільник «Непрочитані», надіслати повідомлення (годинник → ✓), відповісти, відредагувати, реакція подвійним кліком, видалити.
4. Друге вікно `demo2`: написати Андрію. У першому вікні видно «друкує…», повідомлення приходить без перезавантаження, ✓✓ після прочитання.
5. Бот «Погода» → кнопка «Львів» (живі дані Open-Meteo); «Курси НБУ» → «100 USD».
6. Профіль співрозмовника, налаштування: тема світла / темна, активні сеанси.

## 3. Нова функція: «Тихі години» (1,5 хв)
1. «Уявіть: колега в Токіо, у нього зараз ніч». Відкрити чат з тим, у кого зараз тихі години (Kenji, Софія або Олена залежно від часу): фіолетовий банер, кнопка-місяць.
2. Надіслати: бульбашка фіолетова, «завтра о 00:30». Показати меню → «Надіслати зараз» / «Скасувати».
3. Перемикач «Терміново» → повідомлення йде одразу.
4. Сторона отримувача: у `demo` → Налаштування → «Не будити мене вночі», початок трохи раніше за поточний час. З `demo2` написати → у `demo` на списку чатів «1 повідомлення чекає до 08:00 · Отримати зараз».
5. Закінчити тим, що логіку часу покрито тестами з переходом на літній час: показати `npm test` (112 тестів).
