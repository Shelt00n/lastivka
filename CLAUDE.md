# Ластівка — інструкції для AI-агентів

Мобільна веб-версія месенджера в стилі Telegram + нова функція «Тихі години».
Мова інтерфейсу — українська. Код і коментарі — англійською.

## Команди

- `npm run dev` — API (Hono, :3001) + Vite (:5180) з проксі `/api`
- `npm test` — Vitest (сервер, спільна логіка, утиліти клієнта)
- `npm run typecheck` — два tsconfig: server і web
- `npm run check` — typecheck + тести + збірка (те саме, що CI)

## Архітектура

- `src/shared` — DTO, zod-схеми, логіка тихих годин. Використовується і сервером, і клієнтом.
- `src/server` — Hono + PostgreSQL (`pg` у проді, PGlite локально й у тестах). `app.ts` — маршрути, `services/*` — бізнес-логіка, `bots/*` — зовнішні API.
- `src/web` — React 19 + TanStack Query + React Router. Реальний час — SSE (`lib/realtime.ts`).
- 5 сторінок: `/login`, `/`, `/chat/:id`, `/chat/:id/info`, `/settings`. Нові сторінки не додавати.

## Правила безпеки (обов'язкові)

- Кожен доступ до чату/повідомлення — через `requireMember` / `requireVisible`. Чужим — 404, не 403.
- Відкладені повідомлення (`deliver_at IS NOT NULL`) видимі лише відправнику. Не публікувати їх отримувачу.
- SQL лише з параметрами `?`. Імена колонок — тільки з фіксованих мап у коді.
- Вхідні дані — через zod-схеми з `shared/validation.ts`. Зовнішні API — теж через zod.
- Ніколи не повертати `password_hash`, токени, внутрішні поля. Публічний профіль — `toPublicUser`.
- На клієнті жодного `dangerouslySetInnerHTML`; посилання — тільки http(s) через `linkify`.

## Тести

- Нова логіка доступу або тихих годин → тест у `tests/server/*`.
- Часові розрахунки — з фіксованим годинником (`createTestApp(startAt)`), ніколи `Date.now()` у тестах сервера.
- Зовнішні API в тестах — лише через підмінений `fetch`.
- Демо-акаунти (`is_demo = 1`) спільні: профіль, сеанси й видалення для них заборонені на сервері.
- SQL пишемо з `?`, адаптер `db.ts` перетворює їх на `$1..$n`. Транзакції — `ctx.db.tx(async (db) => …)` з `withDb(ctx, db)`.
